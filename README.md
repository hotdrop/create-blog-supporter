# Create Blog Supporter
自分の言葉でテックブログを書くためのAndroid向け執筆支援アプリ。

実装方針は `docs/DesignDocument.md` を参照のこと。恒久ルールと作業時の詳細ルールは `AGENTS.md` と `.codex/skills/` に分離している。

## 現在できること

- Phase1記事メモの作成、一覧表示、編集
- ローカルLLM支援によるタイトル案・目次案の提案
- 目次案の採用時だけPhase2へ遷移し、タイトルと章節を保存
- Phase2記事のタイトル編集、章節一覧表示、章節の追加・削除・並び替え・見出し編集
- 章節ごとの保存済み本文 `content` と編集中本文 `draftContent` の分離
- 章節本文の自動保存、明示保存、保存済み本文への復元
- 章節ごとのLLM相談、概要提案、誤字脱字・表記ゆれチェック
- ユーザー確認済み状態のON/OFFと、全章節確認済み記事の一覧上の「完了」表示
- 全章節が確認済みでタイトルが入力済みの記事のMarkdown出力と共有
